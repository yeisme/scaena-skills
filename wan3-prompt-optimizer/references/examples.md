# 万相3.0 提示词示例

三个完整范例：全能参考(@图片N)、I2V 首帧、24s 多镜长单次。均严格遵循 SKILL.md 输出规范（纯文本、【】〖〗•、【全局设定】五行齐、六层结构、正向排除）。

约定：代码块内是 prompt 正文，从【全局设定】起；形态判定、拆分核算、〖首帧锁定清单〗等属于写作自检，一律写在代码块外，不进正文。提交参数（分辨率/比例/时长/是否改写）不属本技能，示例不提。

## 示例1：多人接力（全能参考形态，@图片N）

优化前（粗略）：三个人站成一排，依次把卡从第一个人传到第三个人，前两人各说一句台词，金额递减。已备好三张角色参考图和一张场景图，按陈总/李总/王总/城堡花园顺序上传。

形态判定：有角色+场景参考图 + 叙事 → 全能参考（reference_image）。图片分开计数：@图片1陈总 @图片2李总 @图片3王总 @图片4城堡花园。

写作说明（不进正文）：形态=全能参考。优化后（prompt 正文）：

```text
【全局设定】
• 画质：高端真人商拍电影质感，超高清真实细节，24fps 电影观感，180°快门自然运动模糊
• 字幕：画面干净通透，字幕不入画
• 音频：环境音、递卡现场音效与镜1、镜2所列两句角色对白清晰分层，无配乐
• 其他：三人五官、发型、服装、卡片道具与光照跨镜头严格一致；全程横向队列站位不变，递卡动作符合真实重力与惯性
• 基调：明亮惬意的豪爽玩笑氛围，午后城堡花园，情绪保持轻松逗趣

【角色设定】
• @图片1（陈总）
• @图片2（李总）
• @图片3（王总）

【场景资产】
• @图片4（城堡花园）：本场景的环境锚点，约束光影/构图/色调

【场景与空间说明】
场景：参照 @图片4（城堡花园）的环境，光线与色调与该图一致
角色空间关系：
• @图片1 位于画左，面朝右邻 @图片2
• @图片2 位于画中，面朝右邻 @图片3
• @图片3 位于画右，身体微转向 @图片2
• 三人横向队列，间距适中，背景层保持低存在感

【镜1】中近景+固定镜头+偏左构图（0-3s）

画面内容：@图片1 右手从口袋取出银行卡，手臂平稳伸向 @图片2，卡面朝上动作干脆，面带轻松笑意；@图片2 面朝 @图片1 右手接卡，表情微带意外。背景虚化，保持低存在感
光影：同 @图片4，午后自然侧光
声音设计：鸟鸣与微风拂过灌木的沙沙声，卡片递出时指尖轻触声
台词：@图片1（豪爽递卡）：给你一个亿，买盆多肉
风格锚点：与 @图片4 光影一致，电影质感，35mm f/2.8 浅景深，暖色调
衔接：@图片2 持卡站立，身体开始转向右侧 @图片3

【镜2】中近景+镜头向右匀速平移+跟随构图（3-7s）

画面内容：镜头向右小幅平移，@图片2 保持接卡姿态转向 @图片3，右手将卡伸出，动作比上镜略随意；@图片3 微微侧头双手接卡，面露惊喜。背景虚化，保持低存在感
光影：同镜1
声音设计：鸟鸣延续，叠加卡片递出轻触声
台词：@图片2（轻快递卡）：五千万，也去买盆多肉
风格锚点：与 @图片4 光影一致，电影质感，35mm f/2.8 浅景深，暖色调
结束状态：@图片3 双手持卡定格，面露惊喜，收于近景

全片保持三人身份、队列站位、服装、卡片和午后光照一致；递卡动作依次连续完成。
```

字数校验：镜1画面约58字、六层合计约118字；镜2画面约55字、合计约112字。均 ≤200 字。角色外观零复述，token 全花在动作/台词/空间上。风格锚点每镜仍完整写一遍（焦段随景别走），不用"同镜1"省略；光影/声音同环境才用「同镜N/延续」复用。

## 示例2：海滩（I2V 首帧形态）

优化前（粗略）：给了一张海边女生的图，让她动起来感受海风。

形态判定：单张首帧图 + 动起来 → I2V 首帧（first_frame ×1）。先做减法自检。

写作说明（不进正文）：形态=I2V 首帧；首帧外观/构图/色调由 VAE 锁定，正文只写运动与变化。写作前自检 · 〖首帧锁定清单〗（内部准备文档，不抄进 prompt，以下信息正文一律省略）：

- 主体：年轻女性，黑色长直发披肩，白色棉麻连衣裙，赤脚站立，双手自然下垂，身体微侧向右
- 场景：海滩，黄昏，海天交界线在画面上三分之一处
- 光影：暖金色逆光从画面右上方，发丝边缘泛金光，面部柔和偏暗
- 风格：低饱和暖色调，胶片质感，画面朦胧带空气感
- 构图：人物在画面右三分之一，左侧留大面积海面，中景平视

优化后（prompt 正文）：

```text
【全局设定】
• 画质：延续首帧既有视觉表现，24fps电影观感，180°快门自然运动模糊
• 字幕：画面干净通透，字幕不入画
• 音频：仅海浪与海风环境音，全片无台词
• 其他：所有运动从首帧状态连续开始，发丝与裙摆的飘动符合真实风力
• 基调：安静舒缓，人物动作放松舒展，整体节奏平稳克制

【场景与空间说明】
全部运动从首帧所示空间、姿态和构图连续开始，镜头仅作缓慢小幅右移。

【镜1】中景+缓慢小幅右移+平视（0-5s）

画面内容：海风从画面左侧吹来，头发向右飘起、裙摆随风轻扬；人物缓缓张开双臂，头部微仰闭眼；远处海浪向岸边涌来，白色浪花渐次铺开。背景虚化，保持低存在感
光影：光照方向与首帧连续，边缘光晕轻微闪烁
声音设计：海浪涌动声与海风呼啸声，连续不断
台词：无
风格锚点：延续首帧既有视觉质感，保持自然运动模糊
结束状态：双臂张开、头发向右飘起、海浪抵达脚边

全片保持首帧既有主体、构图与光照连续；动作舒缓，风向保持一致。
```

要点：外观/场景/色调首帧已锁→全部省略；只写"动起来会变什么"（发丝飘、裙摆扬、张臂、海浪涌）+ 明确运动方向（风从画左、人向画右仰）。〖首帧锁定清单〗是自检文档，不进正文。

## 示例3：24s 多镜长单次（一次生成 + 台词集中前段 + 软截止声明）

优化前（粗略）：会议室里主管宣布项目拿下，先说一句动员的话，随后团队鼓掌，主管走向白板讲方案，约24秒。

时长核算：两句台词共26个中文字，按约4字/秒规划为7秒发声窗口；鼓掌、走向白板和静默讲解共17秒，总计24秒 ≤30秒，不拆，做单单元。

写作说明（不进正文）：形态=全能参考；单生成单元24秒。时间戳和7秒截止均为目标节拍，不承诺绝对秒点。优化后（prompt 正文）：

```text
【全局设定】
• 画质：高端真人职场电影质感，超高清真实细节，24fps 电影观感，180°快门自然运动模糊
• 字幕：画面干净通透，字幕不入画
• 音频：会议室环境音、两句角色对白、掌声与马克笔书写声清晰分层，无配乐
• 其他：目标为全部台词在7秒前结束，镜3、镜4为无对白的纯画面与环境声；主管与成员五官、着装、光照与白板陈设跨镜严格一致，动作幅度小且符合真实物理
• 基调：克制的胜利动员氛围，情绪保持沉稳振奋；会议室为同一连续空间，建立主管与成员之间的180度轴线，机位始终位于轴线同侧，双方屏幕侧保持稳定

【角色设定】
• @图片1（主管）
• @图片2（团队成员A）
• @图片3（团队成员B）

【场景资产】
• @图片4（现代会议室）：本场景的环境锚点，约束光影/构图/色调

【场景与空间说明】
场景：参照 @图片4（现代会议室，长桌、白板、落地窗自然光）的环境，光线与色调与该图一致
角色空间关系：
• @图片1 位于画左长桌一端，站立，面向桌上坐着的成员，正反打中保持画左或中左
• @图片2、@图片3 坐在长桌中段，面向 @图片1，正反打中保持画右或中右
• 两方之间形成固定180度轴线，机位始终位于轴线同侧
• 背景层：白板与落地窗，保持低存在感

【镜1】中近景+固定镜头+正面（0-5s）

画面内容：@图片1 双手撑在桌面上，身体微前倾，目光扫过全桌，说完后嘴角上扬点头致意。背景虚化，保持低存在感
光影：同 @图片4，落地窗自然侧光
声音设计：会议室低混响环境音
台词：@图片1（振奋沉稳）：各位，这个项目我们拿下了，接下来硬仗才开始
风格锚点：与 @图片4 光影一致，电影质感，35mm f/2.8 浅景深，冷暖中性调
衔接：@图片1 直起身，转向桌上的成员

【镜2】中景+缓慢横移+侧向（5-7s）

画面内容：镜头向右侧缓慢平移，@图片2 与 @图片3 抬头鼓掌，脸上带笑意，身体随之微微前倾。背景虚化，保持低存在感
光影：同镜1
声音设计：清脆掌声由稀落转为密集，环境音延续
台词：@图片2（边鼓掌边笑着说）：跟着您干准没错
风格锚点：与 @图片4 光影一致，电影质感，50mm f/2.4 浅景深，冷暖中性调
衔接：掌声渐收，@图片1 迈步走向白板

【镜3】全景+固定镜头（7-15s）

画面内容：@图片1 走向白板，拿起马克笔转身面向众人，抬手指向白板示意；@图片2、@图片3 停止鼓掌、目光跟随聚焦白板。背景虚化，保持低存在感
光影：同前，落地窗自然光
声音设计：脚步声与马克笔轻触白板的细响，环境音
台词：无
风格锚点：与 @图片4 光影一致，电影质感，24mm f/4 中景深，冷暖中性调
衔接：@图片1 笔尖落在白板上

【镜4】特写+缓慢推近（15-24s）

画面内容：镜头缓慢推近白板，@图片1 手持马克笔在白板上勾出阶段流程图，笔迹清晰，另一只手轻点关键点；人物面部不入画。背景虚化，保持低存在感
光影：同前，白板局部反光柔和
声音设计：马克笔书写声，翻页纸声，环境音收尾
台词：无
风格锚点：与 @图片4 光影一致，电影质感，85mm f/2.0 浅景深，冷暖中性调
结束状态：收于白板上的阶段流程图特写，手与笔停在关键节点，人物不入画

全片保持主管与成员身份、着装、屏幕侧、白板陈设和自然光一致；动作从发言、鼓掌到讲解连续推进。
```

要点：① 26个中文字按7秒目标发声窗口规划，加17秒无对白动作，总计24秒≤30秒，保持完整单条生成；② 台词逐字保留并逐句核算：镜1为19字/5秒≈3.8字/秒，镜2为7字/2秒=3.5字/秒，全局为26字/7秒≈3.7字/秒，三者一致；③ "全部台词在7秒前结束"是软截止，只提高前段集中发声的命中率，不保证绝对秒点；④ 无对白镜（镜3、4）台词栏只写"无"两字；⑤ 最后一镜使用"结束状态"，如需跨单元续接再复述角色、服装、道具和光照一致性。
