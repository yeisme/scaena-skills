## 时长、拆分与语速校准

单次生成时长上限 30s。推荐 ≤10s 效果最佳，一致性通常随时长增加而衰减；但 15s、20s 仍是合法且可用的完整单条生成，不因超过 10s 就机械拆分。

### 生成单元决策

先按台词把"需求时长"算出来（需求时长 = ⌈台词字数 ÷ 4⌉ + 计划静默秒数），再按下表定策略——时长是台词的因变量，不要先拍时长再抠台词字数：

| 需求时长 | 策略 |
| --- | --- |
| ≤10s | 单次生成（多分镜一次出，衔接最紧、风格最稳） |
| 10–30s | 默认单次生成，直接把算出的时长写进 duration（≤30 全合法）；建议切镜≤6、无跨场景跳转、结尾声明跨镜一致性。关键动作尽量留足过程时间，1s 短镜仅用于简单反应或短句，不能把"每镜≥3s"当硬门槛 |
| 30–36s（仅超 ≤20%） | 可在不改台词的前提下压进 30s：先压缩静默镜，再提高目标语速；若用户明确要求保持完整时长或单条结构，遵从用户要求 |
| >36s | 默认建议按场景断点拆成多个 ≤30s 生成单元；执行拆分前说明原因，用户要求"完整提示词单条原生重跑"时不得擅自改成分段或后期方案 |

### 实测校准（wan3.0 逐字台词，写作规划用）

- 时间戳与台词截止都是软约束。 它们主要控制相对节拍、先后关系和密度，模型可能整体后移、合并相邻短镜，或把最后一句延伸到视频末尾。可以写「全部台词在 N 秒前结束」提高命中率，但不得宣称绝对秒点会被精确执行。
- 规划字速与实际字速分开。 舒适规划值通常约 4–4.5 个中文字/秒；紧凑对白可尝试约 5–5.4 字/秒，但越紧越容易吞音、弱化声调或挤占结尾收束。
- 全局目标必须与逐句窗口一致。 先逐句计算 该句中文字数 ÷ 该句发声窗口秒数，再计算 全部中文字数 ÷ 全部发声窗口总和；除两字短句、结巴和必要停顿外，各句应落在同一目标区间。若全局写 5.5–6.5 字/秒，而逐句合计只有 4.4 字/秒，提示词内部即自相矛盾。
- 总片长不能代替发声窗口。 语速核算只统计实际分配给对白的窗口，不把建立镜、动作镜和句间静默算入分母。用 需求时长 = ⌈台词字数 ÷ 4⌉ + 计划静默秒数 反推总时长，只是初始规划；之后仍须逐句复核。
- 不要把"提示词窗口缩短"写成"成片已经提速"。 原生音视频模型可能不服从窗口；生成后应交给验证环节，用 ASR 时间戳比较每句起止、累计发声时长和全部对白跨度。ASR 对同音词可能转写错误，专有词最终必须结合人耳复核。
- 短台词不必摊大总时长。 给足时间时，模型可能铺满预算，也可能说完后留出环境声；静默尾镜有助于收束，但同样不是确定保证。
- 段尾动作要显式收住：单元结尾不声明，模型常自行补"起身/走动"收势，与下一单元开头重复。最后一镜写清结束姿态、站位、视线和持续状态。
- 升分辨率不修内容问题：道具串味、镜序漂移、发音波动这类内容层失败，换更高分辨率通常仍会复现；应回到提示词约束、素材和模型能力边界判断。

### 长剧三类常见返工，怎么用设定话术压

这三点在 Good Case 里都不是靠"禁止句"解决的，而是把它写成正面的导演意图，放进【全局设定·其他/基调】和【场景与空间说明】：

- 跨镜空间错位 → 【场景与空间说明】逐人钉死方位（谁坐哪、朝向谁、间距），【全局设定·其他】写一句「机位变化时人物位置、朝向与彼此间距延续上一镜的结束状态，全片为同一间连续宫室」；对话片段在基调里点明「保持稳定正反打，机位在人物同侧」。
- 模型自增台词 → 不用"不许说话"这类否定句。静默镜的台词栏直接写「无」两字即可；如全片台词有明确边界，在【全局设定·基调】写「全片仅 X 句对白，集中在镜N–镜M，其余为纯画面与环境声」，把"哪几镜有台词"讲成正面事实。
- 声音跨镜串流 → 【全局设定·基调】写「每镜环境音起于本镜切镜点、随切镜自然更替」，比逐镜声明更省事，也符合 Good Case 只在必要处点声源的习惯。

另两条易踩：道具/器物问题先按〖器物卡〗判断是不是视觉先验冲突（是则改素材，不在文字上打磨）；四宫格/多视图场景图做 reference_image 时在【场景资产】加一句「@图片N 是同一空间的多视角参考，成片只呈现单一机位画面」，实测不会出分屏。

### 台词时长适配（超长时调时长，不改台词）

优先级：给该镜加时长（总预算内重分）→ 上调生成时长（≤30s）→ 台词跨镜分配（延续跨越切镜，影视常用）→ 仍超上限才拆单元（判据见上）→ 全用尽仍不可行才告知用户"台词超出可生成时长"、经同意后删改。英文缩写（PUA/CEO 等）建议换中文念法避免语音念错，替换前告知用户。

### 专有词与易错发音

Wan3.0 原生音视频不是确定性 TTS，同一提示词不同抽卡可能产生不同咬字、声调和连读结果。发音注记只提高命中率，不构成保证。

- 用户给出的台词文字保持原样；发音信息写在角色表演指导括号内，不改台词正文。
- 使用"汉字字源/语义锚点 + 拼音 + 声调"的组合，例如：「"祖制"两字清晰读作"祖先"的"祖"（zǔ，第三声）和"制度"的"制"（zhì，第四声）」。仅写拼音通常弱于同时给出字源。
- 全局先定义一次；每个实际出现位置再就地强化一次。提交前统计真实出现次数，避免写"四处"但正文实际有五处。
- 紧凑对白仍应给易错词留出清晰咬字空间。优先写「整体连贯，专有词逐字清晰，句末立即收束」，避免"字间极度紧凑"与"逐字清晰"互相冲突。
- 连续 2–3 次仍在同一词上失败时，归类为模型执行波动或能力边界；保持主体提示词稳定抽取候选，不继续无限叠加同义发音说明。是否改用独立配音、后期或其他能力，必须由用户明确授权。

### 单镜头时长经验

无台词镜 1–2s；短台词（≤10字）≥2s；中台词（10–30字）≥3–4s；长台词（≥30字）≥5–6s。计算公式：镜头时长 ≥ 台词字数÷4 + 表演停顿(1–2s)。
