## 设定合规层（写镜头前必建〖设定档案〗）

先区分提示词缺口与模型执行波动。现代玻璃水杯、茶盏里长明火、夜间卸妆还戴凤冠、静默段没环境声，常由设定未钉牢或视觉先验冲突引起；同一完整提示词不同抽卡偶发发音、动作或镜序偏差，则可能属于模型执行波动。前者应修提示词或素材，后者应保持控制变量抽取候选，不能把所有失败都归咎于写法。

扩散模型没有稳定的"设定补全"能力，未写明的部分容易落回训练先验。因此写镜头前要把每一处关键空隙用具体目标状态预先占回来——能被写进条件的才存在，剩下的更容易归于先验（机制见〖否定卡〗推论、〖器物卡〗、〖声音卡〗，此处不重述）。

写第一镜前先产出〖设定档案〗（全片段共享，多单元复用同一份）：

- 世界四要素：时代与地域、场合（礼仪状态，如"夜·寝殿卸妆"）、时段与光源清单（烛台/灯/月光，各在画面哪里）、空间内可用器物清单。
- 三张词表：允许词（目标形制名）、禁用词（直接不出现在 prompt 里，见〖否定卡〗）、易合体对（见〖器物卡〗）。
- 服装状态机：角色在该场合合理的穿着与发式（朝服/常服/寝衣不混用），及跨单元穿着进度声明（"本单元起发髻已散、凤冠已除"）。与角色参考图冲突时，先决定改文字还是换参考图，别指望文字压过视觉先验。
- 声源清单：该空间恒定在响的东西（见〖声音卡〗，静默镜逐镜点名）。
- 光源与反射纪律：声明火焰只允许出现在哪几件器物上；反射面只写受光与高光（见〖器物卡〗）。

一段可直接抄进【全局设定】的模板（Good Case 版）：

```text
【全局设定】
• 画质：[如 高端真人古装宫廷生活电影质感，超高清真实细节，24fps 电影观感，180°快门自然运动模糊]
• 画面纯净度：[全片画幅保持干净，画面上缘、中部与下缘均为连续场景延伸]
• 音频：[如 仅环境音、现场音效与角色对白，无配乐]
• 其他：[跨镜头一致性声明 + 物理真实 + 表演级别，例：角色五官、服装、发型、道具、光照跨镜头严格一致；重力、惯性、碰撞符合真实物理；表演为专业影视演员级，情绪克制内敛]
• 基调：[一句到两句定住本单元情绪与风格边界——把原来要拆成道具/声音/空间/服化"纪律"的内容，合成一句自然的目标状态；例：延续上一段的安静内室氛围，灯光柔和克制，情绪保持稍微放松；场景全程停留在本间寝殿；全片对白仅为用户给定台词]
```

这段模板自身必须先过〖否定卡〗：基调里绝不出现被排除物的名词（火焰、火苗、灯芯、玻璃、静音）——出现＝喂给模型。火只写在"灯/烛台在哪亮"这类句子；声音只写"有哪些连续声源"、不写"不出现静音"；道具靠【场景与空间说明】里的陈设清单自然带出，不单开"道具纪律"行。

现代/产品向同理：档案不是古装专属。产品片要钉死"台面只有 X/Y、无杂物反光、logo 在正面朝镜头"；现代戏要声明"手机为黑色直板、无品牌 logo 露出"等，同样是先占空隙再写镜。

约束：逐镜写作不得引入档案里没有的新器物、新声源、新饰物；需要新增先回档案补一行再写镜，否则单元之间各自发明、拼接必然穿帮。
