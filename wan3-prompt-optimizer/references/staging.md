## 空间锚定与镜头写法

在所有镜头描述前，写一段【场景与空间说明】锁死站位：画左/画右/前景/背景、身体朝向、视线可达性、间距遮挡。

双人对话或对峙场景还要显式建立 180° 轴线：说明轴线由哪两人构成、机位始终位于轴线哪一侧，并固定角色的屏幕侧，例如「沈墨保持画面左侧或中左，盐铁使保持画面右侧或前景右侧」。正反打可以改变景别和肩位，但不得让双方屏幕左右无因互换。镜中切换前后的结束状态与下一镜起始状态必须能在同一空间中连续成立。

形态差异（决定哪些信息要写、哪些省略）：

- T2V：外观、场景、动作、镜头、风格全靠文本，五要素各一两句，不遗漏也不堆砌。
- I2V 首帧 / 首尾帧：首帧/尾帧已由 VAE 像素级锁定构图、外观、光影、色调，prompt 只写运动与变化 + 明确运动方向，不重复静态信息。写前先产出〖首帧锁定清单〗自检冗余。多主体首帧用位置（"画面左侧的女性"）区分，别用角色名。
- 全能参考：参考图分两类，策略完全不同，写前先判断每张 @图片N 属于哪类——
  - 视觉先验（角色设计稿/四视图/场景概念图）：只告诉模型"长什么样"。【角色设定】只做 @图片N（名称） 标识映射、不写外观；【场景资产】只做功能声明、不写场景类型/光线/色调。画面内容只写动作、状态变化、情绪；仅当参考图未覆盖的变化（脏污、汗、孕肚、发髻已散）才补写。给角色再堆外观文本会和视觉先验在 cross-attention 抢权重、反而劣化。
  - 帧锚点（把上一镜的尾帧/某个关键帧截图当 reference_image 传入）：技术上走 R2V，写作层面按 I2V 减法规则处理——画面构图、人物姿态、光影色调都被这张像素级锁定了，全部省略，只写"从这个状态出发接下来发生什么"（动作/运镜/变化）。用于跨单元续接：上一段尾帧作 reference_image（Wan3.0 里 reference_* 与 first_frame/last_frame 互斥，续接段用 reference_image 承载、非 first_frame），并声明"锁定站位朝向、延续上一段光照"。
  - 混合模式：一个 prompt 里可同时有视觉先验图（角色/场景）与帧锚点图（首/尾帧），每张按自己的类型独立套对应策略。挂图 ≤4 张为佳、色温光影要统一。
- V2V 编辑/延长：说清"改什么"+"保留什么"，单次改动 ≤3 个；风格化越大越易丢面部，极端风格丢动作细节。

### 动作具象化（禁止抽象情绪词）

模型不渲染"情绪"，只渲染看得见的动作。抽象情绪词一律翻成可视觉化的身体指令——这是 Good Case 情绪戏耐看的根本，别退回写"她很悲伤""他内心挣扎"。

关键动作必须写成起点 → 连续过程 → 终点，不能只写终点姿态。例如不要只写「跪下低头」，应写「双脚落点固定 → 身体垂直屈膝下降、膝部接触地面 → 双手撑地后伏身低头并保持原位」。跨镜动作还要让上一镜终点与下一镜起点逐项一致，避免人物瞬移、跳姿或动作重复。

| 不要写 | 应该写 |
| --- | --- |
| 她很惊讶 | 身体微微后仰，右手僵在半空，眉毛上挑，嘴巴微张 |
| 他很冷漠 | 垂眼盯着手中茶盏，指尖缓慢摩挲盏沿，全程不抬头 |
| 她强忍情绪 | 喉头极缓地动了一下，眼睫垂下，肩背松了一寸 |
| 递东西 | 右手从胸前取出卡片，手臂自然伸向对方，卡面朝上 |

表演指导里同理：写"柔声、带着心疼""喘而未甘、渐转狠厉"这种能落到呼吸/眼神/嘴角的语气词，别写"情绪复杂""很激动"。

### 视角与转场模板

跨镜衔接用物理空间描述转场，不用剪辑术语（"Cut to…"模型不吃）。叙事常用：

- 正反打：过肩从 A 肩后看 B；反打从 B 肩后看 A。机位保持在人物同侧，对话才不跳。
- 景别收紧推情绪：中景→近景→特写，配合单一核心动作递进。
- Insert/POV：镜头推近至手中器物，屏幕/器物渐占满画面（主观视角），手从画侧滑入。
- 跟随→揭示：背后跟拍穿过门/走廊，推开门强光涌入揭示新场景。
- Whip Pan 甩镜：人物猛然转头→镜头极速横摇成色条→减速后已是新场景（换场景的硬切用）。
- 焦点转移：前景器物清、背景人虚，焦点缓移到人、器物虚成光斑。

### 删冗余的正确姿势（别为了"每镜完整"反堆重复）

相同的层用引用复用，只有真正变化的才重写——每个冗余 token 都在稀释核心信号：

- 光影 / 声音：与上一镜同环境时用「与镜N一致」，不逐字重写。
- 风格锚点：T2V 与全能参考叙事镜每镜写当前镜真正变化的焦段、光圈与渲染锚点；I2V/首尾帧已由帧锁定静态风格时，只写「延续首帧既有风格」加本镜必要的焦段或运动质感，不重复色调、构图和外观。

每个镜头用六层结构（下节格式）。一镜一动作，每镜带与当前生成形态相适配的风格锚点，结尾带背景层抑制。
