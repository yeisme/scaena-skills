# 万相3.0 核心方法论

视频生成是扩散模型：从噪声迭代去噪，文本编码器的语义向量是去噪条件。Wan3.0 支持音视频联合生成与多分镜生成——prompt 里的台词/声音描述既驱动音频，又通过跨模态注意力反哺画面；时间标注是模型可解析的时序条件。

机制 → 写作原则

| 模型机制 | 对 prompt 的影响 | 写作原则 |
| --- | --- | --- |
| 注意力按 token 分配，冗余词摊薄核心条件权重（≠5000 字符硬上限，后者见协议章） | 词越多，每个词的引导力越稀 | 精简优先：删到一个词都不承载新信息为止 |
| 无独立 guidance 参数可调（Wan3.0 未开放 CFG/scale） | 遵循度只能靠文字本身控 | 调遵循度＝删泛词 + 加具体锚点 + 加一致性声明，不是加感叹号 |
| 时空注意力建模帧间变化 | 无时间指令 → 静止或乱漂 | 动作+运镜是核心输入 |
| 去噪步数有限 | 多阶段动作无法精确分配 | 一镜一动作，复杂序列拆镜 |
| 空间构图文本编码不稳定 | 绝对坐标靠不住 | 景别优先，多人同框才用画左/画右辅助；首帧/参考图已锁定时不重复 |
| "不要X"与"X"语义指向同一区域 | 否定式反而召唤X | 禁止否定句，见〖否定卡〗 |
| 光影/风格词是全局色调先验 | 一句锚定整体调性 | 光影和风格是高杠杆信号 |
| 参考图在 cross-attention 里按数量归一化 | 挂图越多，每张引导力越被摊薄、风格先验互相冲突 | 挂图克制（经验 >4 张明显递减），只挂承载关键信息的图，多张色温/光影方向要一致 |
| 音频与画面联合生成、互为条件 | 声音描述能牵引画面节奏 | 用声源事件驱动动作/节奏（门砰→人物一惊），不只写"避免静音" |
| 实测主体/核心动作前置命中更稳（内容驱动、非严格位置优先） | 开头注意力预算最足 | 主体+核心动作放最前，风格氛围靠后 |
| 潜空间无物理单位 | "约2米""30cm"权重极低 | 相对量级优于精确数值（例外：时间标注必须保留） |
| 无世界模型，未指定区域由训练先验的众数填补 | 你没写的部分不会"按设定补全"，只会按语料平均水平补 | 先建设定档案再写镜头：把每处空隙用具体目标状态占回来（见设定合规层） |

三条铁律：一镜一动作 / 不矛盾 / 删冗余。
