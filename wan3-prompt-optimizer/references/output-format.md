## 输出格式（严格执行）

纯文本，禁用一切 Markdown 语法（#、、|、-、``` 等）。一级标题用【】，二级用〖〗，列表用 •。输出正文只放模型可解析的条件信号，不夹带优化说明（说明写在正文之外）。整篇读起来像导演分镜笔记，不像合规检查清单——写"是什么、什么感觉"，不写"禁止什么、必须遵守什么"。

完整结构（Good Case 版）：

正文直接从【全局设定】起。生成模式（T2V/首帧/首尾帧/R2V/编辑）、比例、时长、分辨率都是提交时的 CLI 参数，不写进 prompt 正文。

```text
【全局设定】
• 画质：[高端真人XX电影质感，超高清真实细节，24fps 电影观感，180°快门自然运动模糊]
• 画面纯净度：[全片画幅保持干净，画面上缘、中部与下缘均为连续场景延伸]
• 音频：[仅环境音、现场音效与角色对白，无配乐]
• 其他：[跨镜一致性 + 物理真实 + 表演级别，一句合成]
• 基调：[一句到两句定住本单元情绪与风格边界，使用正向目标状态，如"延续上一段XX氛围；灯光保持XX；情绪维持XX；场景全程停留在XX；全片对白仅为用户给定台词"]

【角色设定】
• @图片N（角色名）    ← 全能参考只做标识映射；T2V 场景改写完整外观（发型/服装/年龄感/气质）

【场景资产】
• @图片N（场景名）：本场景的环境锚点，约束光影/构图/色调

【场景与空间说明】
场景：[参照 @图片N（场景名），时段+关键陈设+光源；不重复场景外观，只补时间/天气]
承接上一段：[多单元续接才写；一句交代前情站位与状态]
角色空间关系：
• @图片N（角色名）[位置/身体朝向/视线/关键姿态]
• @图片N（角色名）[...]
• 背景层：[帷幔/窗外/环境]，保持低存在感

每个镜头
【镜N】景别+运镜(含相对量级)+视角（起始s-结束s）

画面内容：[主体动作+姿态+表情+视线，50-80字，结尾带"背景虚化，保持低存在感"，不重复运镜参数]
光影：[主光源方向+氛围词，1-2句，≤40字]
声音设计：[环境音+动作音效，≤40字；无台词镜按〖声音卡〗点名 1-2 个真实声源]
台词：[@图片N（角色名）]（表演指导）：台词内容。无台词直接写"无"两个字（不写"全片本镜无台词，人物嘴唇闭合"这类防御句）
风格锚点：[每镜都完整写一遍，含具体焦段+光圈，如 "85mm f/2.0 浅景深，低饱和暖木与玉白，柔和烛光"；不要用"同镜1"省略]
衔接：[下一镜初始状态，1句]
```

最后一镜的"衔接"改写成"结束状态：..."，明确交代全片收在什么姿态/站位/道具状态，方便下一单元续接或观众收势。

全部镜头结束后另起一段收束全局：一句到两句话复述一致性约束与本单元情绪边界，例：「全片保持角色、服装、道具、光照跨镜头一致；人物表演克制，动作幅度小；运镜平稳舒缓。」

六层合计 ≤200 字/镜。运镜量级用"缓慢/快速""小幅/大幅""贴地/俯视"等相对词，不写绝对数值（时间标注除外）。有台词的角色用 @图片N（名） 指代。

### 类型适配

叙事：正打/反打 + 景别收紧推情绪 + 台词带表演指导。广告：产品镜稍强光、末镜直视镜头破第四面墙。搞笑：笑点前"环境音骤降半秒"留白 + 动作幅度放大。教程：固定镜头为主、主体居中、手部动作详写。
